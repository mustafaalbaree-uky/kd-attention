# kd-attention

Reproduction package for the paper **"Does Knowledge Distillation Transfer Attention? A Grad-CAM Saliency Study Across Student Architectures"**.

This repository contains every script needed to reproduce all results in the paper from scratch — teacher training, student training (KD, baseline, and seed-43 floor variants), Grad-CAM generation, metric scoring, and figure generation. Three student architectures are covered: ResNet-18, MobileNetV2, and DenseNet-121. Checkpoints and `.npz` arrays are not included (they are large); all of them can be regenerated by following the steps below.

---

## Environment Setup

Requires Python 3.10+ and a CUDA-capable GPU (strongly recommended).

```bash
git clone https://github.com/mustafaalbaree-uky/kd-attention.git
cd kd-attention
pip install -r requirements.txt
```

All hyperparameters (batch size, learning rate schedule, KD temperature, KD alpha, seed) are in `config.yaml`. No changes are needed to reproduce the paper's results.

---

## Dataset

The scripts auto-download ImageNette from fast.ai on first run. No manual download is required — just run step (a) below and the ~330 MB archive will be fetched, extracted to `data/imagenette2-320/`, and the tarball deleted automatically.

If you prefer to download manually:

```bash
wget https://s3.amazonaws.com/fast-ai-imageclas/imagenette2-320.tgz
tar -xf imagenette2-320.tgz -C data/
rm imagenette2-320.tgz
```

The expected layout after extraction:

```
data/
└── imagenette2-320/
    ├── train/
    └── val/
```

## Reproduction Steps

Run all commands from the repository root. Steps must be completed in order; each step depends on outputs from previous steps.

### (a) Train the teacher (ResNet-50)

```bash
python teacher/train_teacher.py
```

Saves `teacher/checkpoints/teacher_finetuned.pth` and `teacher/teacher_training_log.csv`.  
Runtime: ~25 minutes on a T4 GPU (15 epochs).

---

### (b) Train students — repeat for each ARCH in {resnet18, mobilenet, densenet}

**KD student** (soft-label distillation from the frozen teacher):

```bash
python students/ARCH/train_kd.py
```

**Baseline student** (hard-label cross-entropy only, seed 42):

```bash
python students/ARCH/train_baseline.py
```

**Floor baseline** (same as baseline, seed 43 — used to establish the noise floor):

```bash
python students/ARCH/train_baseline_seed43.py
```

Each script saves a checkpoint to `students/ARCH/checkpoints/` and a training log to `students/ARCH/results/logs/`.  
Runtime per script: ~45 minutes on a T4 GPU (30 epochs).

---

### (c) Evaluate accuracy

For ResNet-18 (or any architecture via `--student`):

```bash
python shared/evaluate.py --student resnet18
python shared/evaluate.py --student mobilenet
python shared/evaluate.py --student densenet
```

Writes `students/ARCH/results/metrics/ARCH_accuracy.csv` with top-1 accuracy for teacher, KD student, and baseline.

---

### (d) Generate Grad-CAM arrays

**Main arrays** (teacher vs KD vs baseline, all 3,925 val images):

```bash
python students/ARCH/generate_gradcam_full.py
```

Writes ~3,925 `.npz` files to `students/ARCH/results/gradcam_full/arrays/` and 10 sample overlay figures to `students/ARCH/results/gradcam_full/figures/`.

**Floor arrays** (seed-42 baseline vs seed-43 baseline):

```bash
python students/ARCH/generate_gradcam_floor.py
```

Writes ~3,925 `.npz` files to `students/ARCH/results/gradcam_full/arrays_seed43/`.  
Runtime per script: ~60–90 minutes on a T4 GPU (3,925 images × 3 forward passes each).

---

### (e) Score metrics

**Divergence scores** (JS, Spearman r, SSIM, mIoU — teacher vs KD and teacher vs baseline):

```bash
python shared/score_divergence.py --student resnet18
python shared/score_divergence.py --student mobilenet
python shared/score_divergence.py --student densenet
```

Writes `students/ARCH/results/metrics/ARCH_divergence_scores.csv`.

**Floor scores** (same four metrics, seed-42 vs seed-43 baseline):

```bash
python shared/score_floor.py --student resnet18
python shared/score_floor.py --student mobilenet
python shared/score_floor.py --student densenet
```

Writes `students/ARCH/results/metrics/ARCH_floor_scores.csv`.

---

### (f) Generate figures and summary statistics

```bash
python shared/summarize.py --student resnet18
python shared/summarize.py --student mobilenet
python shared/summarize.py --student densenet
```

Writes `students/ARCH/results/metrics/ARCH_summary_stats.json` (all table values) and five figures to `students/ARCH/results/figures/`.

**Optional — floor comparison figures** (10 side-by-side seed-42 vs seed-43 panels):

```bash
python shared/generate_floor_figures.py --student resnet18
python shared/generate_floor_figures.py --student mobilenet
python shared/generate_floor_figures.py --student densenet
```

## Hardware Note

All training and Grad-CAM generation for this paper were run on Kaggle with dual NVIDIA T4 GPUs. Approximate runtimes on a single T4:

| Step | Approx. time per architecture |
|---|---|
| Teacher training (15 epochs) | ~25 min |
| Student training (30 epochs each) | ~45 min |
| Grad-CAM generation (main) | ~75 min |
| Grad-CAM generation (floor) | ~50 min |
| Metric scoring | ~5 min |

CPU-only execution is possible but significantly slower (estimate 10–15× longer for training and GradCAM steps).
